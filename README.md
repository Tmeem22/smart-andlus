# ذكاء الأندلس — Smart Andlus

منصة تواصل تعليمي ذكية (مشروع كامل: Frontend + Backend).
بهوية خاصة **Smart Andlus** — ليست جهة حكومية رسمية، والدخول ببيانات تجريبية.

## المزايا
- **ولي الأمر**: شات ذكي (Fireworks / GLM) يجيب عن الطالب، ويختار بذكاء متى يعرض **رسم بياني** أو **تقرير كامل** أو **نسبة حضور**.
- **المعلم**: رفع ملفات مادته فقط (PDF/صورة/نص) — تُرسل للمدير للمراجعة.
- **المدير**: إضافة/تعديل معلمين (مادة، اسم، هوية، صلاحيات)، إدارة الطلاب والدرجات، مراجعة الملفات (فتح داخل الصفحة، قبول/رفض/تعديل/مراسلة المعلم)، تغذية **عقل البوت**.
- **مراسلة** لحظية بين المعلمين والإدارة (زي واتساب) + **إشعارات** + محاكاة مكالمات، عبر Socket.IO.

## التقنيات
- Backend: **Node.js + Express + Socket.IO** — مخزن JSON (`server/data.json`)، رفع ملفات بـ multer، تشفير كلمات المرور (scrypt).
- Frontend: HTML + CSS + JavaScript (بدون إطار)، تصميم أندلسي RTL.
- الذكاء: نموذج **Fireworks** — المفتاح في `.env` على السيرفر فقط.

## التشغيل
```bash
npm install
npm start
```
ثم افتح: http://localhost:8731

## حسابات تجريبية
| الدور | المستخدم | المرور |
|------|----------|--------|
| مدير | `admin` | `1234` |
| معلم | `sara` أو `noura` | `1234` |
| ولي أمر | `parent` | `1234` |

## الأمان
- المفتاح في `.env` (متجاهَل بـ `.gitignore`). **لا ترفعه لأي مكان عام.**
- لو انكشف المفتاح: ألغِه من لوحة Fireworks وأنشئ غيره، وحدّث `.env`.
- كلمات المرور مشفّرة داخل `data.json`.
